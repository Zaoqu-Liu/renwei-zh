# Syntactic Shells

Syntactic shells are repeatable sentence frames that make different topics sound as if they were written by the same model.

The goal is not to ban every frame. The goal is to notice when a frame is carrying the argument instead of the underlying evidence.

## A. Extreme Judgment

Signals:

- "真正 X 的是..."
- "最 X 的地方在于..."
- "关键并不在 A，而在 B"

Risk:

The sentence sounds deep before it has earned the conclusion.

Rewrite:

1. Remove "真正/最/关键".
2. State the claim.
3. Add the evidence or boundary.

Example:

> 真正可贵的是这种产品视角。

becomes:

> 这次改动有价值的地方，是客户少配了两套权限表。

## B. Personified Negation

Signals:

- "数据不在乎..."
- "市场不相信..."
- "血管不认..."

Risk:

It turns analysis into slogan. It can work in essays, but it is usually too theatrical for business, academic, and technical writing.

Rewrite:

Replace the personification with the mechanism.

> 市场不相信概念。

becomes:

> 客户续费看两件事：上线后节省了多少人力，以及出错时能不能追责。

## C. Dramatic Revelation

Signals:

- "扯下遮羞布"
- "数字摆得清楚"
- "真相浮出水面"

Risk:

It exaggerates conflict and often substitutes drama for evidence.

Rewrite:

Name the actual comparison, table, metric, or event.

## D. Mild Concession Shell

Signals:

- "X 当然有它的 Y"
- "不是没有道理"
- "更麻烦的是..."

Risk:

Useful in human argument, but models overuse it to sound balanced.

Rewrite:

Keep the concession only if it changes the conclusion. Otherwise delete it.

## E. Deictic Location Closure

Signals:

- "正卡在这条裂缝里"
- "问题就在这里"

Risk:

It closes with a gesture instead of a conclusion.

Rewrite:

State the unresolved constraint or next decision.

## Practical Rule

When a paragraph has more than one shell, rewrite the paragraph from the underlying facts instead of editing sentence by sentence.
